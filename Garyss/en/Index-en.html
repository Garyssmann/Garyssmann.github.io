Layout.

Web page layout is the creation of a hypertext document structure based on HTML markup, usually using style sheets and client-side scripts, so that the design elements look similar to the mockup..

Layout using technologies and methodologies: BEM, Flex, Grid, Gulp, SCSS, CSS3/HTML5, JavaScript.

Working with me you save:

  • Money. I develop high-quality adaptive layout based on desktop mockups, which significantly saves your budget and does not require ordering additional design mockups.
  • Time on writing technical specifications — I predict the logic of each element's work. Minimum questions, maximum results.
  • Nerves. Non-structural requests and improvements are already included in the price! So if you missed some details in the design, they will be added to the layout at your request without extra arguments or costs.
